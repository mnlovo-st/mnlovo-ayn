# MNLOVO AYN · عين

خزنة ذكية للآيفون: حسابات وكلمات سر ورموز 2FA، صور وفيديو وملفات مشفّرة، وتذكيرات ما تخليك تنسى.
كل شي مشفّر على الجوال بـ **AES-256**، ومفتاح Face ID محفوظ داخل شريحة **Secure Enclave**.

## ٢. بناء ملف IPA مجاناً (بدون ماك)

GitHub يبني التطبيق لك على أجهزة ماك مجانية.

1. سوّ حساب في **github.com** (إذا ما عندك).
2. اضغط **New repository** ← سمّه `mnlovo-ayn`.
   - **Public**: البناء مجاني بلا حدود. الكود ما فيه أي أسرار (إعدادات Supabase تنكتب داخل التطبيق).
   - **Private**: يشتغل بس دقائق البناء الشهرية المجانية محدودة.
3. ارفع ملفات المشروع كلها:
   - الأسهل: نزّل **GitHub Desktop** ← Clone الريبو ← انسخ محتوى مجلد `MNLOVO-AYN` داخله ← Commit ← Push.
   - أو من الموقع: **Add file ← Upload files** واسحب كل الملفات والمجلدات (تأكد إن مجلد `.github` انرفع).
4. روح تبويب **Actions** ← بتلقى «Build IPA» شغّال (أو اضغط **Run workflow**). ياخذ ٥–١٠ دقايق.
5. لما يخلص: روح **Releases** (يمين صفحة الريبو) ← نزّل **MNLOVO-AYN.ipa**.

> إذا فشل البناء: افتح الـ Action ← نزّل **build-log** ← ارسله لي وأصلحه.

## ٣. تثبيت الـ IPA على الآيفون من ويندوز

1. ثبّت **iTunes** و **iCloud** من موقع Apple نفسه (مو من Microsoft Store).
2. نزّل **Sideloadly** من sideloadly.io وثبّته.
3. وصّل الآيفون بالكيبل ← اضغط «Trust» على الجوال.
4. افتح Sideloadly ← اسحب `MNLOVO-AYN.ipa` ← اكتب Apple ID ← **Start**.
5. على الآيفون:
   - **الإعدادات ← عام ← إدارة VPN والجهاز** ← اختر حسابك ← **وثوق**.
   - **الإعدادات ← الخصوصية والأمن ← وضع المطوّر** ← تشغيل (الجوال يعيد التشغيل).

**مهم:** مع Apple ID المجاني التطبيق يشتغل ٧ أيام ثم تعيد التثبيت (بياناتك ما تنحذف إذا ثبّته فوقه بنفس الطريقة). **AltStore** يجدده تلقائياً إذا تبي. مع حساب مطوّر مدفوع يصير سنة.

## ٤. إعداد Supabase المجاني (للكود على الإيميل والنسخ الاحتياطي)

1. سوّ حساب في **supabase.com** ← **New project** (اختر أقرب منطقة، واحفظ كلمة سر قاعدة البيانات).
2. **SQL Editor ← New query** ← الصق محتوى `supabase/setup.sql` ← **Run**.
3. **Authentication ← Emails (Templates)**: في قالبي **Magic Link** و **Confirm signup** أضف السطر:
   ```
   كود الدخول: {{ .Token }}
   ```
   (بدونه يوصلك رابط بدل كود).
4. **Project Settings ← API Keys**: انسخ **Publishable key** (يبدأ بـ `sb_publishable_`)، ومن زر **Connect** أعلى الصفحة انسخ **Project URL** (`https://xxxx.supabase.co`).
5. في التطبيق: **الإعدادات ← إعداد Supabase** ← الصقهم ← **حفظ واختبار**.

ملاحظات:
- خدمة الإيميل المدمجة في Supabase مخصصة للتجربة: ترسل عدد قليل من الإيميلات بالساعة، وغالباً بس لإيميلات أعضاء المشروع. استخدم نفس الإيميل اللي سجّلت فيه بـ Supabase وبيشتغل عادي. إذا تبي إيميلات بلا حدود اربط SMTP مجاني (مثل Resend أو Brevo) من **Authentication ← SMTP Settings**.
- المشروع المجاني يتوقف إذا ما انستخدم أسبوع؛ تفتح لوحة Supabase وتضغط **Restore** ويرجع.
- السيرفر يستلم بياناتك **مشفّرة** فقط. ما يقدر يقرأها أحد.

## ٥. أشياء لازم تعرفها

- **مفتاح الاسترجاع** هو الشي الوحيد اللي يرجع حسابك إذا نسيت كلمة السر (مع الإيميل والجوال وتاريخ الميلاد). اكتبه على ورقة.
- **2FA:** زر «أضف إلى تطبيق كلمات السر» يفتح الإعداد مباشرة. إذا ما فتح: انسخ «مفتاح الإعداد» وفي تطبيق كلمات السر اختر **إعداد رمز التحقق ← إدخال مفتاح الإعداد**.
- **الدخول:** كلمة السر تطلب دائماً رمز 2FA. Face ID يفتح مباشرة، وكل ١٤ يوم يطلب كلمة السر + الرمز للأمان.
- **كلمة سر الطوارئ:** تفتح خزنة وهمية فاضية بنفس اسمك ونفس رمز 2FA ونفس كلمة سر الأقسام. Face ID دائماً يفتح الخزنة الحقيقية، فتحت الإجبار استخدم كلمة الطوارئ.
- **الشعارات في الحسابات** ألوان وحروف (مو شعارات حقيقية) عشان التطبيق ما يتصل بأي موقع ويكشف الخدمات اللي تستخدمها.
- **الودجت:** مع التوقيع المجاني أحياناً ما تنتقل بيانات «App Group»، فالودجت ممكن يطلع فاضي بينما الإشعارات وDynamic Island يشتغلون عادي.
- **Siri:** العبارات بالإنجليزي («Add a reminder in AYN»). تقدر تضيفها بالعربي من تطبيق **الاختصارات** باسم تختاره.
- **الأصوات:** موجودة في `App/Resources/Sounds/`. استبدل أي ملف `.wav` بتأليفك بنفس الاسم وابنِ من جديد.

## ٦. هيكل المشروع

```
project.yml                 تعريف المشروع (XcodeGen)
.github/workflows/          بناء الـ IPA تلقائياً
App/Sources/Core/           التشفير، الحساب، التخزين، التذكيرات، Supabase، Siri
App/Sources/UI/             الواجهات (الإنترو، العين، الدخول، الأقسام، الإعدادات)
App/Resources/              الأيقونة والألوان والأصوات
Widget/                     الودجت والـ Dynamic Island
Shared/                     بيانات مشتركة بين التطبيق والودجت
supabase/setup.sql          إعداد السحابة
tools/make_assets.py        يولّد الأيقونة والأصوات
```

### التشفير باختصار
- مفتاح رئيسي عشوائي 256-bit يشفّر كل شي (AES-GCM).
- هذا المفتاح نفسه مشفّر ٣ مرات: بكلمة السر (PBKDF2-SHA256، ٦٠٠ ألف دورة)، بمفتاح الاسترجاع، وبمفتاح داخل Secure Enclave يحتاج Face ID.
- الملفات الكبيرة تتشفّر على قطع ١ ميغا، كل قطعة مربوطة برقمها عشان ما ينعبث بترتيبها.
- صور المتطفلين تتشفّر بمفتاح عام وقت ما يكون التطبيق مقفل، وما تنقرأ إلا بعد ما تفتح أنت.
