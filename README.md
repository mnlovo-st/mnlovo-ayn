## ١ · بناء ملف IPA مجاناً (بدون ماك)

GitHub يبني التطبيق على أجهزة ماك مجانية.

1. افتح تبويب **Actions** ← **Build IPA** ← **Run workflow**. ياخذ ٥–١٠ دقايق.
2. لما يخلص: **Releases** ← نزّل `MNLOVO-SAVER.ipa`.

> فشل البناء؟ افتح الـ Action ← نزّل **build-log**.

## ٢ · تثبيت الـ IPA من ويندوز

1. ثبّت **iTunes** و **iCloud** من موقع Apple (مو من Microsoft Store).
2. نزّل **Sideloadly** من [sideloadly.io](https://sideloadly.io).
3. وصّل الآيفون بالكيبل ← اضغط «Trust» على الجوال.
4. افتح Sideloadly ← اسحب الـ IPA ← اكتب Apple ID ← **Start**.
5. على الآيفون:
   - **الإعدادات ← عام ← إدارة VPN والجهاز** ← حسابك ← **وثوق**.
   - **الإعدادات ← الخصوصية والأمن ← وضع المطوّر** ← تشغيل.

مع Apple ID المجاني التطبيق يشتغل ٧ أيام ثم تعيد التثبيت فوقه بنفس الطريقة (بياناتك ما تنحذف). **AltStore** يجدده تلقائياً. مع حساب مطوّر مدفوع يصير سنة.

## ٣ · إعداد Supabase (الكود على الإيميل + النسخ الاحتياطي + البوت)

1. [supabase.com](https://supabase.com) ← **New project**.
2. **SQL Editor** ← الصق `supabase/setup.sql` ← **Run**.
3. **Authentication → Emails**: الصق قالبي `supabase/email/magic-link.html` و `confirm-signup.html`.
4. **Authentication → SMTP Settings**: اربط Gmail بـ **App Password** (١٦ حرف)، أو Resend/Brevo لعدد أكبر.
5. **Project Settings → API Keys**: انسخ الـ **Publishable key** والـ **Project URL** وحطهم في التطبيق: **الإعدادات ← إعداد Supabase**.
6. الدوال: `supabase/functions/saver-telegram` و `saver-admin` (الاثنين `verify_jwt: false`).

> المشروع المجاني يتوقف إذا ما انستخدم أسبوع — `.github/workflows/keepalive.yml` يطنّشه يومياً ويمنع هذا.

## أشياء لازم تعرفها

- **مفتاح الاسترجاع** هو الشي الوحيد اللي يرجّع حسابك إذا نسيت كلمة السر. اكتبه على ورقة.
- **كلمة سر الطوارئ** تفتح خزنة وهمية فاضية بنفس اسمك ونفس كل شي. Face ID دائماً يفتح الحقيقية.
- **خزنتك ما تنفتح من السيرفر أبداً** — ولا حتى من مكتب الدعم. التشفير على جوالك أنت.
- **الشعارات في الحسابات** ألوان وحروف، مو شعارات حقيقية، عشان التطبيق ما يتصل بأي موقع ويكشف الخدمات اللي تستخدمها.
- **الودجت** مع التوقيع المجاني أحياناً ما تنتقل بيانات App Group، فيطلع فاضي بينما الإشعارات و Dynamic Island يشتغلون عادي.
- **رمز الدرهم والريال الجديدين** مرسومين داخل التطبيق من أشكالهم الرسمية، لأن خطوط iOS للحين ما فيها الشكلين.

## التشفير باختصار

- مفتاح رئيسي عشوائي 256-bit يشفّر كل شي (AES-GCM).
- هذا المفتاح مشفّر ٣ مرات: بكلمة السر (PBKDF2-SHA256، ٦٠٠ ألف دورة)، بمفتاح الاسترجاع، وبمفتاح داخل Secure Enclave يحتاج Face ID.
- الملفات الكبيرة تتشفّر على قطع ١ ميغا، كل قطعة مربوطة برقمها عشان ما ينعبث بترتيبها.
- صور المتطفلين تتشفّر بمفتاح عام (Curve25519) وقت ما يكون التطبيق مقفل، وما تنقرأ إلا بعد ما تفتح أنت.
- الوصية هي الاستثناء الوحيد: نسخة منها تبقى على السيرفر عشان تنسلّم بعدك، وتنمسح لحظة ما توقف الخاصية.
